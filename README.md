# Paul Tupciauskas — Consulting Website

A lightweight, single-page consulting site focused on industrial AI, intelligent systems, automation, multi-agent architectures, and enterprise integration. It uses plain HTML and CSS, with no build step or external dependencies.

## Editing

- Edit `index.html` to update the content, navigation, and contact details.
- Replace the email and LinkedIn placeholders in the contact section with your own details and links when ready. An email link uses the format `mailto:your-address@example.com`.
- Edit `styles.css` to change colors, typography, spacing, and responsive layouts.

To preview the site, open `index.html` in a browser. You can also serve the repository locally with `python3 -m http.server` and visit `http://localhost:8000`.

## Publishing with GitHub Pages

1. Commit the site files and push them to the repository's publishing branch (usually `main`).
2. In the repository on GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose the publishing branch and the `/ (root)` folder, then save.
4. Once deployment finishes, visit `https://paul-tupciauskas.github.io/`. Changes pushed to the publishing branch will be published by GitHub Pages.

The repository must have GitHub Pages enabled; availability and visibility depend on the repository and account settings.
